📷 Sobre las fotografías

Las fotos no se pueden subir masivamente desde esta interfaz web por límites de tamaño del navegador. Para cargar fotos junto con los datos, usa el comando de consola: 

python manage.py importar_estudiantes datos.csv --carpeta-fotos /ruta/a/las/fotos

En la columna foto del archivo pon solo el nombre del archivo (ej: Garcia_Juan.jpg) y el comando lo buscará en la carpeta indicada.
