👤 Guía de Usuarios – Sistema de Gestión

Cómo crear usuarios con y sin acceso al panel de administración

📋 Tipos de usuario

Tipo ¿Accede al sitio? ¿Accede a /admin/? Uso típico
Usuario normal ✔ Sí ✘ No Docentes, coordinadores que solo consultan el CRUD
Staff ✔ Sí ✔ Sí (limitado) Personal que necesita gestionar datos desde el admin
Superusuario ✔ Sí ✔ Sí (completo) Administrador del sistema

🟢 Opción A — Usuario sin acceso al admin (recomendado para docentes)

Desde la consola (una sola vez)

# Crear usuario normal — NO tiene acceso a /admin/
python manage.py shell

Dentro del shell de Django escribe:

from django.contrib.auth.models import User

User.objects.create_user(
    username='nombre_usuario',
    password='contraseña_segura',
    first_name='Nombre',
    last_name='Apellido',
    email='correo@colegio.edu.co',
    is_staff=False,       # NO accede a /admin/
    is_superuser=False,  # NO es superusuario
)
💡 Resultado: Este usuario puede iniciar sesión en /login/, ver estudiantes, registrar asistencia y usar todo el CRUD del sitio, pero si intenta entrar a /admin/ verá un error de permisos.

Desde el admin de Django (si ya eres superusuario)

1

Ve a /admin/ e inicia sesión con tu cuenta de superusuario.

2

Clic en Usuarios → Añadir usuario.

3

Completa nombre de usuario y contraseña. Clic en Guardar y continuar editando.

4

En la pantalla siguiente, deja desmarcadas las casillas:

☐ Activo en el staff ☐ Es superusuario
Solo debe estar marcada la casilla "Activo".
5

Clic en Guardar. ¡Listo!

🟡 Opción B — Usuario con acceso al admin (staff)

Desde la consola

from django.contrib.auth.models import User

User.objects.create_user(
    username='coordinador',
    password='contraseña_segura',
    is_staff=True,        # SÍ accede a /admin/
    is_superuser=False,   # Pero NO es superusuario
)
⚠️ Importante: Un usuario staff puede entrar al admin, pero solo verá los modelos para los cuales el superusuario le haya otorgado permisos explícitos (Agregar / Cambiar / Eliminar / Ver).

🔑 Cambiar la contraseña de un usuario existente

Opción rápida — consola

python manage.py changepassword nombre_usuario

Desde el admin

Ve a Admin → Usuarios, selecciona el usuario y usa el enlace "Cambiar contraseña" en la parte superior derecha del formulario.

🚫 Desactivar un usuario (sin borrarlo)

from django.contrib.auth.models import User

u = User.objects.get(username='nombre_usuario')
u.is_active = False
u.save()
# Para reactivarlo:
u.is_active = True
u.save()
💡 Tip: También puedes hacerlo desde el admin desmarcando la casilla "Activo" en el formulario del usuario.
